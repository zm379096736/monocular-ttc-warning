# 论文写作提纲

## 暂定题目

**基于预训练视觉模型与可解释时序融合的单目车辆碰撞时间估计方法**

英文：**Monocular Vehicle Time-to-Collision Estimation via Pretrained Vision Models and Interpretable Temporal Fusion**

## 摘要写作模板

1. 背景：单目碰撞预警成本低，但光流 TTC 易受抖动、遮挡和检测波动影响。
2. 问题：传统单帧或固定平滑难以根据观测可靠性动态利用历史信息。
3. 方法：冻结检测、跟踪和光流上游；构造目标级物理与置信度特征；使用轻量 MLP 输出显式时序权重并融合连续 TTC；以 FOE 动态走廊筛选碰撞目标。
4. 实验：KITTI Tracking，传统方法、GRU/LSTM 和消融对比。
5. 结果：必须运行后填写真实 MAE、RMSE、危险 F1 与速度，不得提前编造。
6. 结论：根据真实结果判断假设是否成立。

## 1 绪论

- 单目碰撞预警的应用价值与成本优势。
- 传统光流 TTC 的噪声、外点和时序不稳定问题。
- 预训练视觉模型提高上游表征质量，但不自动解决 TTC 时序可信度问题。
- 本文把创新集中在下游可解释融合，而非重新训练大模型。

### 预期贡献（需由实验验证）

1. 提出冻结预训练视觉上游与轻量下游分离的单目 TTC 框架。
2. 提出置信度驱动的 MLP 时序加权方法，以显式权重融合物理 TTC。
3. 设计 FOE 动态碰撞走廊和轨迹异常重置机制，减少相邻车道与 ID 切换干扰。
4. 在统一上游缓存上完成传统算法、循环网络及模块消融的公平比较。

## 2 相关工作

- 基于尺度变化、光流散度与 FOE 的 TTC。
- 单目深度与学习式 TTC。
- 目标检测、多目标跟踪和稠密光流预训练模型。
- 时序滤波、LSTM/GRU 与可解释权重融合。

## 3 方法

### 3.1 问题定义

- 输入：单目视频帧序列。
- 输出：前方目标连续 TTC 与三级风险。
- 训练时真值可来自 LiDAR/三维标注，推理不使用这些传感器。

### 3.2 冻结上游

- YOLO11m 目标检测。
- ByteTrack 数据关联。
- RAFT-Large 稠密光流。

### 3.3 纯视觉运动建模与碰撞走廊

- 背景掩膜与 RANSAC 单应性。
- FOE 鲁棒估计。
- 目标框和动态碰撞走廊横向重叠率。

### 3.4 目标级 TTC 与质量特征

\[
z_i=[T_i,\Delta T_i,E_i,C_i,Q_i,\Delta A_i]
\]

逐一说明物理意义、归一化和异常值截断。

### 3.5 可解释时序权重 MLP

\[
s_i=W_2\operatorname{ReLU}(W_1z_i+b_1)+b_2
\]

\[
w_i=\operatorname{softmax}(s_i),\qquad
\widehat T_t=\sum_iw_iT_i
\]

### 3.6 损失函数

\[
L=L_{SmoothL1}+\lambda L_{trend}
\]

### 3.7 风险分级与冷启动

- TTC 固定阈值。
- 下降趋势只允许升级。
- 少于 5 帧使用单帧 TTC。
- 轨迹中断、ID 切换和 TTC 突变时重置缓存。

- 权重可视化是否符合预期。
