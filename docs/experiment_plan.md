# 实验计划与记录模板

## 1. 研究假设

在冻结检测与光流上游的条件下，置信度驱动的 MLP 时序加权能够降低异常帧对单目 TTC 的影响，并在不牺牲可解释性的前提下提高连续 TTC 精度和危险场景召回率。

## 2. 公平比较原则

- 所有下游方法使用相同的 YOLO、ByteTrack、RAFT 缓存。
- 所有学习方法使用相同的训练、验证、测试序列划分。
- 标准化统计量只能由训练集计算。
- 超参数只能根据验证集选择；测试集只在最终配置确定后运行。
- 报告至少 3 个随机种子的均值和标准差。
- 不能把相邻帧随机拆到不同数据集。
